Recursos

Tudo que um kanban precisa — e nada de banco de dados

O motor é genérico e os dados são seus. Você aponta o Basalt para uma pasta (o vault) e ele versiona tudo em git automaticamente.

Git-native

Cada criação, edição ou movimentação vira commit automático. Histórico, diff e branch da sua vida real — sem lock-in.

Tarefas em markdown

Frontmatter + corpo markdown. Legível por qualquer editor, grep, script — e por você daqui a cinco anos.

Kanban & Lista

Colunas por status com grupos macro, arrastar-e-soltar, cores por opção, filtros tipados e ordenação por qualquer campo.

Editor rico, estilo Notion

Blocos por /, imagens, checklists e blocos de código com realce de sintaxe — tudo com ida e volta perfeita para markdown.

Dashboard

Criadas, finalizadas, lead time e quebras por status/pessoa. Gráficos que respeitam as cores das suas colunas.

Plugins & auto-update

Extensões puxadas direto do GitHub e atualização automática do app — instala em silêncio e reabre sozinho.

Feito para a era da IA

Se é markdown, a IA entende

Como tudo é texto plano em arquivos, qualquer assistente (Claude, Copilot, scripts) lê, cria e edita suas tarefas direto no repositório. Sem API, sem exportação, sem fricção.

--- T-042.md --- tipo: bug status: Em andamento modulo: Estoque branch: fix/saldo_negativo # Saldo negativo após estorno Ao estornar uma NF, o saldo fica reservado em vez de voltar. - [x] Reproduzir - [ ] Corrigir db_functions/
Por que "Basalt"

A rocha que nasce em colunas

O basalto se resfria formando colunas retas e paralelas — a junção colunar. É a imagem exata de um quadro kanban. E, como a rocha, é escuro por natureza: tema dark de ponta a ponta.

Instalar

Comece em minutos

Baixe o app desktop (Windows) ou rode do código. Na primeira abertura, aponte para a pasta do seu vault e pronto.

Baixar a última release App não assinado — o Windows pode mostrar o SmartScreen no primeiro uso ("Mais informações → Executar assim mesmo").
1

Clone

git clone github.com/JairAragao/basalt

2

Instale & rode

npm install && npm run electron:dev

3

Aponte o vault

Escolha a pasta onde suas tarefas .md vão viver. O Basalt versiona o resto.

Requer Node ≥ 18 e git instalado. Também roda no navegador (npm run dev).
